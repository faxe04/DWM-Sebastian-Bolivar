## Descripción
El caso 4 conciste en desarrollar una aplicacion web e-commerce para una cafeteria y resposteria llamada 'Café & Aroma'. Este caso exigia requisitos escenciales.

En esta primera etapa se darrolló el frontend de la aplicacion con sus funcionalidades de navegacion, intereaccion, resposive, entre otros. Esto actualmente esta funcionando con datos dummy hardcode simulando una lo que seria una llamada mas adelante a una API. El objetivo principal es mostrar el diseño, estructura, funcionalidad y responsive.

## Tecnologías utilizadas

### React
Se utilizó React para construir la interfaz debido a la facilidad de trabajar con componentes reutilizables y mantener una estructura modular.

### Vite
Harramienta que se utilizó para crear y ejecutar el proyecto React.

### JavaScript
Lenguaje principal utilizado para imlementar la logíca del frotend.

### React Router
Se utilizó React Router para administrar la navegación entre las distintas vistas y trabajar con parámetros en la URL para los filtros.

### CSS
Css de utilizó para el diseño visual de la aplicación.
Ademas mencionar que se utilizo ayuda de modelos LLM para los estilos con el objetivo de optimizar tiempo pero tambien aprender y conseguir el diseño planeado.
